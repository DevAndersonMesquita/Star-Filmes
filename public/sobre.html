Sobre o StarFilmes

O StarFilmes é uma plataforma web desenvolvida com o objetivo de facilitar o acesso e a organização de filmes de maneira simples, rápida e intuitiva.

O sistema permite que usuários explorem conteúdos organizados por servidores, além de oferecer uma interface moderna e responsiva, pensada para proporcionar uma boa experiência de navegação.

Este projeto foi desenvolvido como parte de um processo de aprendizado em desenvolvimento web, aplicando conceitos de front-end e back-end, além de boas práticas de programação.

Tecnologias utilizadas

  • HTML5
  • CSS3
  • JavaScript
  • Node.js
  • Express
  • Banco de Dados

Objetivo do projeto

O StarFilmes foi criado com o objetivo de evoluir habilidades em desenvolvimento web, criando uma aplicação funcional e organizada, simulando um sistema real de gerenciamento e exibição de filmes.
